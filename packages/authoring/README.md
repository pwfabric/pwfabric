# @pwfabric/authoring

`defineBlock` and `defineFactory` — write your own blocks against the same contract the first-party ones use.

```bash
pnpm add @pwfabric/authoring
```

Part of [PWFabric](https://github.com/pwfabric/pwfabric). Documentation, the
other packages and the licensing model live in that repository.
