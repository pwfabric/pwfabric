# @pwfabric/runner

Runs a pwapp — routing, navigation, visitor sign-in. This is what makes a downloaded app work on any static host.

```bash
pnpm add @pwfabric/runner
```

Part of [PWFabric](https://github.com/pwfabric/pwfabric). Documentation, the
other packages and the licensing model live in that repository.
